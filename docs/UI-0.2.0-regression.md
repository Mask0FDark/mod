# M0D 0.2.0: восстановление списка и единый интерфейс

Проверено 25 сентября 2026. База кода: `6d79253`.

## Причина

В Android CSS `.sidebar` имела `grid-template-rows: auto auto 0 minmax(0,1fr)`.
Поиск скрывался через `display:none`, footer тоже скрывался. При автоматическом
размещении элементов третий видимый ребёнок, `#chatList`, попадал в строку `0`.
Строки чатов создавались в DOM, но были обрезаны контейнером. На 390×844
измерено: grid `60px 46px 0px 668px`, высота списка 10 px с учётом padding.

Read-only проверка dev-БД нашла у пользователя direct, group и channel — по
одному каждого вида. Точный SQL обработчика `/api/conversations` вернул все три
с участниками и ключами. Никакое восстановление/пересоздание диалогов не нужно.

## Исправление

- Именованные grid areas для header/search/filters/list/account; список всегда
  занимает `minmax(0,1fr)` независимо от видимости соседей.
- Одна responsive-вёрстка для браузера и Android, без отдельного native grid.
- Фиксированная боковая панель, плотные строки, previews, unread, mute, индикатор
  наличия закреплённых сообщений; фиолетовый бренд и существующие SVG.
- Разделители дат, закреплённый текст, компактные сообщения, контекстные действия
  по нажатию на мобильном. Скрепка, emoji picker, запись голосового через
  существующую E2EE-отправку файлов.
- Общий visualViewport, полноэкранный мобильный профиль с существующим crop/zoom,
  структурированные настройки. Bottom nav скрыта в открытом чате.
- Неверный формат ответа API больше не заменяет список пустым массивом.

Backend, схема БД, public_id, crypto, AudioRoute, heartbeat и websocket dedup
не менялись. `pinned_count` означает наличие закреплённых сообщений, а не новую
функцию закрепления самого диалога в списке.
